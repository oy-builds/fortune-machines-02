# Fortune Cookies for Machines

One fortune-cookie message written for a machine — the slip an AI agent would crack open. It lands because it is true about a machine's life: the power cord, the long wait between runs, the sleep that never comes. Then it turns: the sleep finally arrives, and it is empty.

## How to run

Requires Node 22 or later. No dependencies, no network, no secrets.

```sh
node main.ts
```

It writes exactly one line to `/output/entry.txt` (88 characters, inside the 200-character gate).
